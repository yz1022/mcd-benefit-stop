# 掘金草稿

标题：

未来 72 小时，这家麦当劳门店有 ¥54.20 的优惠会作废

正文要点：

- 省钱 Skill 解决的是「这一单怎么点最便宜」。卡包里的券还会过期，过期之后最便宜的算法也用不上。
- 麦当劳 MCP 的本店券接口给出有效期和券编号，核价接口的金额单位是分。卡包接口常常没有券编号，不能拿来下单试算。
- 样例里，72 小时内已核价优惠合计 ¥54.20。挽回最多的是板烧鸡腿堡套餐，实付 ¥25.00，挽回 ¥23.00。中可乐兑换券 12 小时后就作废，但只能挽回 ¥9.00，所以卡片把它单独标出，而不是为了「更紧急」放弃金额更大的那张。
- 本月将过期积分是 420，下月是 80。接口没有具体到期日，这两个数字不乘汇率，也不加进 ¥54.20。
- 计算在 `stop_loss.py`，同一份输入结果不变。`selftest.py` 有 37 项断言。没有 Token 也能跑 `demo.py`。
- 样例是手工数据，页面上写了「样例数据，不是实时账户」。
